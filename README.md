# Tools

一个在线工具合集，纯 HTML 实现，可直接用浏览器打开，也支持 GitHub Pages 部署。

## 工具列表

### Word
- [word-extract-images](word/word-extract-images/) — 从 Word 文档中提取图片

### Excel
- [excel-add-toc](excel/excel-add-toc/) — 为 Excel 工作簿添加目录页

### Image
- [image-stitch](image/image-stitch/) — 图片拼接工具

## 使用方式

直接浏览器打开对应目录下的 `index.html`，或通过 GitHub Pages 访问：
`https://Hazel-0222.github.io/tools/工具名/`
