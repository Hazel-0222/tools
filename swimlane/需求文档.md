# 泳道图（Swimlane）工具 需求文档

> 由「当前已实现代码 + 历史沟通」反推整理，供你直接编辑修改。
> 标记：[已实现] = 当前代码已支持；[已确认] = 你已经拍板、代码尚未落地的点；[待实现] = 计划中未做；[待确认] = 需要你拍板。
> 工具本体：`swimlane/index.html`（单文件，唯一真源）。

---

## 1. 一句话定位

浏览器端纯前端绘制「**工种 × 阶段**」矩阵泳道图的工具：工种为列（顶部一行）、阶段为行（左侧一列），步骤放进交叉格，格间连箭头线。注意事项列支持内联超链接，可导出 PNG / PDF / Excel / JSON，单文件零依赖、打开即用。

## 5. 数据模型

```json
{
  "schema": 2,
  "title": "开新服流程",
  "roles":  [ { "id": "r1", "name": "策划", "bg": "#E7F3F8" } ],
  "phases": [ { "id": "p1", "name": "设计阶段" } ],
  "steps":  [ { "id": "s1", "phase": "p1", "role": "r1",
                "text": [ { "t": "撰写策划案", "l": null },
                          { "t": "查看范例", "l": "https://…" } ] } ],
  "edges":  [ { "id": "e1", "from": "s1", "to": "s2", "label": "通过" } ]
}
```

- [已实现] 步骤与备注共用**通用富文本分段数组** `[{t: 文本, l: 链接|null, b: 加粗, c: 字色hex|null}]`：文本段**可加粗、可改字色**（步骤+备注通用，Notion 色板 9 色 + 默认黑）；`l` 链接字段仅备注列启用（步骤模式隐藏链接/移除按钮）；避免 HTML 注入，JSON/Excel 导出干净
- [已实现] 注意事项另存图片段 `{img, iw, ih}`（base64 dataURL 内嵌 + 原始宽高，最长边压缩到 640px），与文本段混排；整体存 `doc.notes:[{phase, role, sub, seg}]`：`sub` 为空 = 简单阶段整段一格；`sub` 为子阶段 id = 该子阶段带一格（新增子阶段时旧整段备注自动归入第一个子阶段）。天然适配本地草稿/JSON 存取与 PNG/PDF 导出
- [已实现] `localStorage` 草稿自动保存（防抖 350ms），刷新/关闭后恢复
- [待实现] JSON 文件的导出 / 再导入
